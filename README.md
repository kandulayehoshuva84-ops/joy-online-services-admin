# JOY ONLINE SERVICES Admin Portal

Mobile-friendly React/Vite + Supabase admin portal.

Features:
- Admin email/password login
- Dashboard
- Application creation/list/status management
- Private PDF/JPG/PNG document upload
- Signed URLs for secure document viewing

Storage bucket used by the app: Documents

Before running, execute admin_portal_setup.sql in Supabase SQL Editor.

Create .env from .env.example with your Supabase URL and publishable key.
Never put a service-role/secret key in the frontend.
